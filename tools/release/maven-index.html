MCHeli: Revived Maven repository

The public API of MCHeli: Revived for addon mods, with its sources and javadoc. No account or token is needed.

repositories {
    maven {
        url = 'https://ivomens.github.io/MCHeli-Revived/maven/'
        content { includeModule 'com.ivomens.mcheli', 'mcheli-revived-api' }
    }
}

dependencies {
    compileOnly 'com.ivomens.mcheli:mcheli-revived-api:<api version>'
}

The mod jars for development runs come from the GitHub releases; the addon template shows how to declare them.

See docs/API.md and the addon template.

Published by the release workflow. Versions are never replaced once published.
